# Telegram Bot для наложения текста на изображения

Простой Telegram бот, который накладывает текст на изображения. Бот получает картинку и текст от пользователя, а возвращает изображение с наложенным текстом по центру с полупрозрачным фоном.

## Возможности

- Наложение текста на изображения
- Автоматическое центрирование текста
- Полупрозрачный фон под текстом для лучшей читаемости
- Автоматическая подстройка размера шрифта под размер изображения
- Поддержка различных форматов изображений

## Требования

- Python 3.8+
- Telegram Bot Token (получите у [@BotFather](https://t.me/BotFather))

## Установка

### 1. Клонируйте репозиторий

```bash
git clone <url-репозитория>
cd tg-image-policy
```

### 2. Создайте виртуальное окружение (рекомендуется)

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте переменные окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте файл `.env` и добавьте токен вашего бота:

```
TELEGRAM_BOT_TOKEN=your_actual_bot_token_here
```

### 5. Запустите бота

```bash
python bot.py
```

## Как получить токен бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания нового бота
4. Скопируйте полученный токен и добавьте его в файл `.env`

## Использование

### Команды бота

- `/start` - Приветственное сообщение и инструкции
- `/help` - Справка по использованию
- `/text <ваш текст>` - Установить текст для наложения на изображение

### Пример работы

1. Запустите бота командой `/start`
2. Установите текст командой:
   ```
   /text Привет, мир!
   ```
3. Отправьте боту любое изображение
4. Получите обработанное изображение с наложенным текстом

## Технические детали

### Использованные библиотеки

- **python-telegram-bot** - для работы с Telegram Bot API
- **Pillow (PIL)** - для обработки изображений

### Функционал обработки изображений

Бот выполняет следующие операции с изображением:

1. Получает изображение от пользователя
2. Конвертирует его в формат RGB (если необходимо)
3. Вычисляет оптимальный размер шрифта на основе размеров изображения
4. Центрирует текст на изображении
5. Добавляет полупрозрачный черный фон под текстом
6. Рисует белый текст поверх фона
7. Сохраняет и отправляет результат пользователю

## Решение проблем

### Бот не запускается

- Убедитесь, что токен бота корректно указан в файле `.env`
- Проверьте, что все зависимости установлены: `pip install -r requirements.txt`

### Ошибка при обработке изображения

- Убедитесь, что файл является действительным изображением
- Проверьте, что в системе установлены необходимые шрифты

### Шрифт отображается некорректно

Бот пытается использовать следующие шрифты в порядке приоритета:
1. DejaVu Sans Bold (`/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf`)
2. Liberation Sans Bold (`/usr/share/fonts/truetype/liberation/LiberationSans-Bold.ttf`)
3. Стандартный шрифт PIL

Если текст отображается мелко или некорректно, установите шрифты DejaVu:

**Ubuntu/Debian:**
```bash
sudo apt-get install fonts-dejavu
```

**CentOS/RHEL:**
```bash
sudo yum install dejavu-sans-fonts
```
